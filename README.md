# 还能做什么

根据冰箱里的食材，AI 为你推荐可以做的菜肴。

![还能做什么](https://img.shields.io/badge/AI-DeepSeek-orange) ![License](https://img.shields.io/badge/license-MIT-green)

## 功能特性

- 🍳 **智能菜谱推荐**：基于现有食材，AI 推荐可做的菜肴
- 🥬 **食材分类选择**：蔬菜、肉类、调料、蛋类、主食分类预设
- 🍽️ **菜品数量可选**：支持 3 / 5 / 8 道菜推荐，默认 5 道
- 👨‍🍳 **详细烹饪步骤**：包含步骤、所需调料、卡路里估算
- ⭐ **难度可视化**：星级显示烹饪难度
- 💾 **API Key 本地保存**：自动保存，下次无感使用
- 📱 **响应式设计**：完美适配手机和电脑

## 快速开始

### 1. 获取 API Key

访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并获取 API Key。

### 2. 打开页面

直接在浏览器中打开 `what-can-i-cook.html`。

### 3. 输入 API Key

首次使用时点击"还能做什么？"，输入 API Key 后按回车即可。API Key 会自动保存到本地。

### 4. 添加食材

- 点击预设标签快速添加
- 在输入框手动输入食材名称，回车或点击添加

### 5. 生成菜谱

选择想要推荐的菜品数量，点击"还能做什么？"按钮。

## 使用说明

### 界面操作

| 操作 | 说明 |
|------|------|
| 添加食材 | 点击预设标签或手动输入 |
| 删除食材 | 点击食材标签上的 × |
| 选择菜品数 | 点击 3道 / 5道 / 8道 |
| 生成菜谱 | 点击"还能做什么？" |
| 返回修改 | 点击底部的"✕ 返回" |

### 菜谱信息

每道菜包含以下信息：
- 📍 菜名
- ⭐ 难度（简单/中等/复杂）
- ⏱ 预计烹饪时间
- 🔥 卡路里估算
- 👨‍🍳 详细烹饪步骤
- 🧄 所需调料
- 📦 缺失食材提醒

## 技术栈

- 纯 HTML + CSS + JavaScript
